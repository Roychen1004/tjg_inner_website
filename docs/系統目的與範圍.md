# 系統目的與範圍

## 目的

鐵正綱工程（土建＋鋼構）的內部管理系統。取代 Excel、紙本與 LINE 追蹤，
回答三個問題：

1. **案子做到哪**——每個專案、每批構件、每個工項在哪一站，卡住了沒
2. **錢在哪**——該收的收了沒（應收）、該付的付了沒（應付）
3. **未來會不會缺錢**——收付加總的現金流預測，累計轉負的那一格

## 範圍（2026-08-13 簡化後）

**做**：專案與請款分期（建案一頁完成）、進度補登（辦公室事後輸入）、
應收四狀態、應付三狀態（核可與付款分離）、現金流預測（三級確定性）、
專案損益、附件（合約/圖說/照片，含權限與防護）。

**不做**（要用時從 git 或封存文件恢復）：
現場手機即時回報、簽收觸發自動請款、庫存/資產/產線管理、
KPI 快照排程、薪資與簽核流程。正式帳務仍由會計軟體處理。

## 使用者

天天用的是**經營者與會計**兩個人。第三種角色「檢視」保留給
未來想讓同仁看進度用（看不到任何金額）。

## 硬約束

- 正式機 8GB RAM：常駐目標 ≤1.5GB（現況約 210MB）
- 響應式網頁，非 App；正式環境無 Node 程序
- 五個分頁，每個畫面回答一個問題；元素通不過「砍掉會有人做不了事嗎」就砍
