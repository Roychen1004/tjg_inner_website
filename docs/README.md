## 封存

`封存/` 是歷史，僅供考古，內容**不再對應現在的系統**：

- 舊詳細規格（Use Case／User Story／API／資料模型／KPI）與被簡化掉的功能設計（庫存/資產/簽收觸發）
- `流程制改版規劃.md`——D37 改版的規劃書，已執行完畢，結論都併入決策紀錄與員工手冊
- 三份 `鐵正綱ERP_*.xlsx`——最初的欄位與埠號規劃（現以程式與 `deploy/.env.sample` 為準）
- 成本管理總作業手冊（docx）——最早的制度藍本，系統簡化後只實作其中一部分

要恢復某個功能時，從這裡＋git 歷史找回設計與程式。
