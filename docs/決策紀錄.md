## 仍然有效的舊決策（一行版）

- **D01** 一張 tracking_unit 表吃鋼構批次與土建工項，靠階段模板分流
- **D05** 不用 Redis/Celery，排程走 cron；8GB 主機常駐目標 ≤1.5GB
- **D07** 全部列表強制分頁；看板不分頁但限 300 張卡且必須指定範圍
- **T06** 範圍外的資料回 404 不回 403——不讓人從錯誤碼推測資料存在
- **D22** 金額一律 Decimal；狀態異動包在交易裡；錢的歷程不可竄改（往回轉必填原因）
- **D26** 客戶/廠商/員工在前端維護；階段模板在 Django Admin
- **D28** 員工不刪只停用——歷史紀錄掛在人名下
- **D31** 應付與應收鏡像對稱；核可（老闆）與付款（會計）分離；
  月結＝當月月底再加 N 天；金額存未稅、現金流一律 ×1.05、損益用未稅
- **B1** 支票開票日 ≠ 兌現日，現金流用兌現日；沒填票期時用預計付款日（偏樂觀）
- **D32** 附件掛專案/追蹤單元/應收款三處；magic bytes 驗檔；照片剝 EXIF 重編碼
- **D33** 合約與發票類附件跟著金額權限走——欄位擋了、檔案沒擋等於沒擋
- **D34** X-Accel-Redirect 下 nginx 不轉發自訂標頭，nosniff 要在 nginx 再設一次
