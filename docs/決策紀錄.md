   工段完成度＝已完成量÷項目數量（沒填數量用已分配量當分母）
4. **排程的主要負責人預設＝新增專案的人**——建案生成的每張單元
   自動掛在建立者名下（不發通知），之後逐列改派
5. **甘特圖調整**——滿版（跳出置中窄欄）；左欄與條上文字加大、永遠不消失
   （條太短時整組文字掛在條旁）；**條的中間寫流程名稱**（如「表面處理」）；
   滾輪縮放敏感度調高（0.0015→0.004）；專案篩選從晶片改成下拉選單（單選）
