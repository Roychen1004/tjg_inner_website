# 員工手冊

> 2026-08-18（D40）權限改版。六個分頁、四種角色，畫面上的提示就是操作說明——
> 這份手冊只講畫面上看不到的事。

## 系統在做什麼（30 秒版）

追五件事：**案子每一步做到哪、今天輪到誰做什麼、公司雜務誰在管、錢收付到哪、未來會不會缺錢。**

```
總覽      今天有什麼要處理（需要關注清單）
專案      一個案子＝勾選的流程＋請款分期＋構件批次（卡片上直接看迷你甘特）
追蹤看板  流程看板（卡在哪一步）｜甘特圖（日曆時間軸）｜員工（誰手上有什麼、該月完成什麼）
我的任務  被指派給我的事：開始、回報、完成（分「案子」與「行政」兩種來源）
行政      公司非案子的事務（繳費、打掃、報稅…）：大日曆／條列兩種看法
金流      應收（業主的錢）｜應付（付包商的錢）｜現金流預測
設定      客戶、廠商、員工（大家都能查，改要經理）
```

四種角色（帳號與密碼在 [帳號密碼.md](帳號密碼.md)）：

| | 看得到 | 能編輯 |
|---|---|---|
| **經理**、**系統管理員** | 全部八個分頁 | 一切（含行政事項與類別） |
| **會計師** | 全部八個分頁 | 金流（應收／應付／付款）＋自己的任務。「核可付款」仍是經理按 |
| **員工**（繪圖師、行政人員、工廠員工） | 除了金流的分頁都看得到，**看不到任何金額** | 只有「我的任務」裡指派給自己的事（含行政事項打勾） |
| **檢視**（備用） | 同員工的唯讀範圍 | 不能編輯 |

案子照**五大階段的流程模板**走：
需求釐清與估價 → 報價協商與簽約 → 深化設計與備料 → 加工與現場施工 → 驗收與收款結案。
D49 起流程是**每個案子自己的**：建案時選模板（預設「標準流程」19 項）、
勾要走哪些、**拖曳調整順序**，每個階段還能加目錄上沒有的自訂流程；
模板本身（有幾套、各套長什麼樣）由經理／系統管理員在 設定 → 流程模板 維護。

## 經理的一頁

每天打開看**總覽**就夠了：

1. **需要關注清單**——逾期流程、進行中沒負責人、可請款放著沒開單。清單空的就沒事
2. 專案卡片的**迷你甘特**：五條 bar＝五大階段，深色＝做完的比例，
   紅色三角＝有流程逾期。不用點開就知道那個案子準不準時
3. 每週看一次 **金流 → 現金流預測**：累計轉負的那一格＝要調頭寸的時候。
   D49 起頁面最上面有「**公司現有現金**」輸入（只有你和系統管理員看得到，
   會計師也看不到）——填了之後累計從這個數字起算，轉負＝現金真的見底；
   旁邊可切「**時間軸**」用甘特的方式看錢什麼時候進出（滾輪縮放、拖曳平移；
   D55 起一個來源兩行——「收」一行、「付」一行，行政收支自成一列）
4. 想知道「錢實際上花到哪裡去了」看 **金流 → 收支明細**（D55）：
   一天一天列出收了什麼、付了什麼、是哪個案子或哪一件行政，
   可以只看案子或只看行政（選「只看案子」時旁邊還能挑**單獨一個案子**，
   已結案的也挑得到），按月翻頁。已收／已付＝真的進出過帳戶，預計＝還沒發生
5. 追蹤看板的甘特圖右上角有**小日曆**（D49）：點一天（或點兩天選範圍）
   看那段日子有哪些案子的哪些流程在跑、哪些錢要進出，點了直接開卡片。
   D55 起點完第一下、游標移過去時，那一段會**先變淺藍**，確認要選的範圍再點第二下
6. 接新案前看**統計**分頁（D52）：每種工作一工做得出多少（產能）、
   各材料越買越貴還是越便宜（單價走勢）、每類流程平均一次花多少——
   全部由日常操作自動累積，這頁只有你和系統管理員看得到產能
   （會計師只看得到金額區塊，員工整頁看不到）

D40 起**進度與排程只有經理（和系統管理員）能改**——建案、勾流程、指派、
排程、批次推站、補登進度全在你（或你授權登你帳號的人）手上；
會計師的編輯範圍只剩金流，員工只能動自己被指派的任務。

只有你能做的事還有：**核可付款**（金流→應付）、**核准變更追加單**（專案明細）、
**維護基礎資料**（設定分頁——別人看得到但改不了）、
**刪除專案**（編輯專案的最下面——建錯的才刪，已有請款收款紀錄的刪不掉；
只是沒成交或不做了，改「案件狀態」就好）。

## 建案與派工（經理）

**建案（1 個表單）**——專案分頁 →「新增專案」：

1. 案名、客戶、負責人；**簽了約填合約金額，還在估價就填估價金額**
   （估價金額會用「預估級」進現金流，未成交就把案件狀態改掉）
2. **選模板、編流程（D49）**——選一套流程模板（預設全勾），把不需要的取消、
   **拖曳（或 ↑↓）調順序**、每階段最下面可加自訂流程（如「拆除舊棚架」）。
   之後隨時「編輯流程」加減與重排
3. **請款分期照合約抄**——每期可掛「**觸發流程**」：
   該流程一完成，那期自動轉可請款並通知你和會計師，不用人盯
4. 合約 PDF 與設計圖直接在表單裡選好，按「建立」一次完成

**派工**——展開案子 → 流程排程表 → 點一列，**打開就是表單**（不用再按編輯）：
指派主要負責人（對方會收到通知、出現在他的「我的任務」）、
排預計起訖（**甘特圖與現金流預測都靠這兩個日期**）。
每張單元的主要負責人**預設是建案的人**（D41）——沒改派之前，每件事都掛在你名下。

卡片最上面是**整張卡片唯一的文字區塊「工作內容」**（D43）——要做什麼、範圍、
注意事項全寫在這裡（建案時從流程目錄抄預設，改完離開欄位就存，只影響這個案子）；
產出物與完成條件以唯讀小字收在同一格。以前排程表單裡另外的「詳細內容」已併入這裡。

**工作項目與工段分配（D41）**——同一步常常不只一件事：「採購」要買鐵材 200 噸、
螺栓 2000 支。在單元卡片的「工作項目」按「＋新增項目」逐筆記：內容物、數量、單位。

1. 在**每個項目自己**的「工段」列加它會經過的關卡（D45）——
   鐵材加 切割中→噴漆中、螺栓加 已下訂單→已到貨，各走各的；
   輸入框會建議大家之前用過的字，直接沿用不必重打。
   「未開始／已完成」內建在頭尾，不用加；項目的狀態從下拉選單挑
2. 頭尾（未開始／已完成）以外的每個狀態＝一個**工段**，按工段旁的「分配」
   派給員工：**一次勾好幾個人，填總量就自動平均分**——200 噸鐵材的切割
   勾 4 個工廠員工、填 200，每人各拿 50 噸；按「**最大**」一鍵填入剩餘量。
   分配時要選**工作類型**（D52 必選——焊接、切割、泥作…，產能統計靠它分類；
   系統會依工段用字自動帶上次選的，通常不用動手，「＋新類型」可即時新增），
   也可填**注意事項**（D49）——你的叮嚀會進對方的通知、
   在他「我的任務」的卡片上特別標出來（📌 經理叮嚀）。
   工段旁的「還可分 X」提醒你還有多少沒派出去；
   每個人收到通知、在自己的「我的任務」回報做了幾噸
3. 誰做完自己的分量，你（主要負責人）就收到通知，附那個工段的彙總
   （如 切割中 200/200，100%）。卡片開著會**每 10 秒自動更新**，不用重整
4. **進度全自動（D44）**：項目總進度＝各工段完成度的平均（兩個工段各占 50%）；
   單元的進度＝各項目總進度的平均。**沒有手動回報進度這回事**——
   數字全部從分配的回報算出來（批次彙總的單元照舊由批次過站算）

**卡片上的錢（D45/D46）**——排程下面還有兩個金流入口（只有看得到金流的人看得到）：
- **收款連結**：把應收期別掛在這一步並指定收款會計師——流程一完成，
  那期自動轉可請款、會計師收到通知並出現在他「我的任務」的「輪到我收款」。
  **一步只掛一期、一期只掛一步**；流程被重啟或取消連結時，
  還停在「可請款」的期別會自動退回「未到」（已請款的不自動改，發警示請人工處理）
- **新增應付帳款**（完成按鈕旁邊）：金額、付費對象、預計付費日、付款方式，
  登錄即掛在這一步；金流→應付的列表會標「流程：XX」讓你追得回來；
  之後的核可（經理）與付款（會計師）照舊在 金流 → 應付

**員工視圖**——追蹤看板第三個分頁（D46）：一人一卡看**每個員工手上有什麼、
這個月完成了什麼**（負責的流程＋被分到的工段分量），月份可前後切換。
派工前先看這頁，誰有空一目瞭然。D52 起每份分配還標**三色狀態**：
「未開始」（紅＝對方還沒按開始）／「進行中 第 N 天」／「今日已回報」，
以及累積的**工數**（一人一天＝1 工，記在當天有回報的那件、同日多件均分；
覺得不準可在流程卡片那一列直接填工數蓋過，留空＝回到自動計）。

**構件批次**——階段 4 的實體單位（如「1F鋼柱 80支」），在**展開案子 → 構件批次**
新增與推站。批次過站，下料加工/表面處理/運輸進場/現場安裝四個流程的進度
**自動彙總**，不用重複填。

**專案主線不用推**——主線階段由流程進度自動判定：階段裡有流程開始就亮起、
全部完成就打勾。加工還沒收尾、現場已開工時，兩個階段會同時亮——這是實況，不用硬選。

**甘特圖 Excel 有兩種**（檔名都是 產圖日期＋案名＋用途）：
- **工期規劃（業主版）**——收合的專案卡片右側、收款進度下方「下載工期規劃」。
  簽約前給業主看：只有流程與起訖工期，**沒有**進度、狀態、負責人與圖例
- **進度追蹤（內部版）**——展開案子 → 流程排程表右上「下載進度追蹤」。
  含負責人、狀態、進度與圖例，顏色照狀態著色
  兩種右邊都是日期網格（工期短一天一格、長一週一格，整片框線）。

## 行政事項（經理／系統管理員維護，全員可看）

公司非案子的事——繳網路費、打掃、報稅、消防申報——都放在**行政**分頁。

**回報完成**：點日曆或清單上的事項會開一張卡片——看內容、上傳收據／照片，
再按「回報完成」。不在格子上直接打勾（太容易誤觸），
而且繳費、打掃這種事常要留憑證，檔案就傳在同一張卡裡。

**看**：預設是一個大日曆（月），右邊可以切「條列」（依日期排的清單，
往前多看 14 天，逾期的繳費不會因為跨月就消失）。工具列下方一行小字：
「這段期間 N 件／已完成 N／逾期未做 N」——完成狀況一眼看完。
色塊顏色＝類別顏色；打勾的會劃掉。

**新增**（只有經理與系統管理員看得到按鈕）：右上「+ 新增事項」，先選型態

* **臨時**——一次性的事，填一個日期就好
* **例行**——每週（可複選星期幾）／每月（幾日；填 31 小月自動算月底）／
  每年（幾月幾日）。存檔後系統**自動把未來每一次都排進日曆**，每一次個別打勾。
  已經排出來的某一次不想做，直接在日曆上點掉它——**不會再長回來**。
  改規則（例如打掃從週五改週四）只會重排今天以後還沒做的，做完的歷史不動

**金額（D55）**：新增／修改事項時可以填金額，並選「支出」「收入」或「參考」。
選支出或收入就會出現在**金流 → 收支明細**與現金流預測裡
（網路費、清潔費、規費本來就是公司的錢）；
例行事項填一次，長出來的每一次都帶著這個金額。不涉及錢的（打掃、送件）留空就好。
完成＝錢已經進出了；還沒完成＝預計。

**「參考」是什麼（D56）**：預估的錢——估價還沒談定、開個會大概要花多少。
它只顯示在這件事上（灰字寫「參考」），**不會**算進金流的收入與支出，
也不進現金流預測（沒談定的數字混進帳本，累計那條線就不是錢了）。
談定之後把它改回「支出」或「收入」，才會進帳。

**指派**：可以指派多人，也可以先不指派。被指派的人會收到通知，
事情會出現在他的「我的任務 → 📅 行政事項」，**任一人打勾就算整件完成**。

**類別**：右上「類別」可以增刪改（名稱＋顏色）。預設有繳費／打掃／其他。
已經用過的類別不給刪，但可以停用（歷史才不會變孤兒）。
D56 起**新增事項的表單裡就能開新類別**：類別下拉最後一項「＋ 新增類別…」，
填名字按建立（或按 Enter），建完直接選起來，不用先把表單關掉跑去「類別」那頁。
顏色系統先配一個，要換再去「類別」改。

**誰能回報完成**：被指派的人自己按，經理也可以代按。
打勾**不計入產能工數**（行政雜務不該稀釋接案產能），但經理會收到完成通知，
頁面上也看得到是誰完成的。

## 設定頁能改什麼（經理／系統管理員）

2026-09-01（D54）起 **Django Admin（/admin）已經整個移除**——
所有維護都在網站上，不再有第二套後台。設定頁五個分頁：

| 分頁 | 改什麼 |
|---|---|
| 客戶 | 名稱、聯絡人、帳期（帳期會影響現金流預測的收款日推算） |
| 廠商 | 供應商／分包商／外包加工／運輸行 |
| 員工 | 帳號、角色、部門、重設密碼（離職的人請停用，不要刪） |
| 流程模板 | 案子要走哪些流程（幾項、叫什麼、順序） |
| 批次站別 | **構件批次**走幾站、每站叫什麼、什麼顏色、停幾天算「卡住」 |

批次站別的規則：改名稱／顏色／停滯天數會立刻套用到所有批次；
已經有批次停在上面、或有歷程紀錄的站**不給刪**（刪了歷史就斷了），
但可以「停用」——停用的站不會再出現在軌道上，需要時可以再啟用。

**調順序（D55）**：流程模板與批次站別都可以**拖曳**——按住每一列左邊的握把
（⠿）往上下拖，放開就存。編號跟著位置即時變（3.4 拖到前面就變 3.3）。
手機或平板拖不動時用旁邊的 ↑↓。
⚠️ 站別的順序就是批次往前走的路線，改了之後所有批次的「下一站」都照新順序。

**誰能用哪一頁**：完整的角色×頁面對照表在 `docs/角色權限矩陣.xlsx`
（五種角色、一個帳號一種）。

## 員工的一頁（繪圖師、行政人員、工廠員工）

除了金流，每個分頁都看得到（總覽、專案、追蹤看板、行政、設定）——
**但都是唯讀**，也看不到任何金額。你能動的只有自己被指派的任務。

登入直接進**我的任務**。每個區塊都標了來源（D53）：
**📅 行政**＝公司雜務（繳費、打掃…），**🧊 案子**＝專案上的工作。

1. 「**📅 行政事項**」（D53）——被指派到的公司雜務，左邊方框**點一下就是做完了**，
   經理會收到完成通知。逾期的日期會變紅字。行政事項不計入產能工數
2. 「**分給我的工作**」（D41）——如「鐵材 切割中 50 噸」。
   動工那天先按「**▶ 開始**」（D52——經理看得到你開始了）；
   **當天收工前把完成量填上**：做多少填多少，填到滿＝做完，
   主要負責人會收到通知。天天回報，你的產能紀錄才不會少算
3. 逾期的流程排最上面（紅色），先處理
4. 接到新任務、新分配或新行政事項會有通知（右上角鈴鐺）
5. 點任務看這一步的工作內容（要做什麼、產出物、完成條件都在那一格）
6. **開始** → 做 → 在「分給我的工作」填完成量（流程進度會自動算，不用另外回報）
   → **完成**。完成不用等主管確認
7. 圖檔、照片直接傳在任務的檔案區

看不到金額是設計，不是壞掉。

## 會計師的一頁

先看**我的任務**最上面的「**輪到我收款**」（D45）——經理把應收期別指定給你之後，
觸發流程一完成你就會收到通知，那期出現在這裡，點過去直接開單。

**金流分頁有四個子頁**：應收（錢進來）、應付（錢出去）、
**收支明細**（D55：一天一天的流水帳——哪天收了什麼、付了什麼、是哪個案子或哪件行政；
可切「全部／只看案子／只看行政」，只看案子時可再挑單獨一個案子，按月翻頁）、
現金流預測（未來哪個月會缺錢）。
明細裡「已收／已付」是真的進出過帳戶的錢，「預計」是還沒發生的。

日常就三個動作，全在**金流**分頁：

| 事情發生 | 你做什麼 |
|---|---|
| 觸發流程完成（自動）| 那一期**自動**變可請款，你會收到通知——直接開單就好 |
| 條件到了但沒掛觸發 | 應收 → 那一期按「變更狀態」→ 可請款 |
| 單開出去了 | → 已請款（填請款日，**預計收款日會自動算**：請款日＋客戶帳期） |
| 錢進來了 | → 已收款 |
| 包商送計價單來 | 應付 → 登錄計價（**金額填稅後實際金額**，D48；**可以掛在流程上**，之後查「這一步花了多少」就有；分期付款在流程卡片的「新增應付帳款」選期數）。買材料請按「**拆明細**」填 品項×數量×單價（D52）——金額自動加總，「鋼材每噸多少」的走勢就從這裡累積；零星款照舊只填總額 |
| 經理核可後付款 | → 已付款。**開支票一定要填票期**——現金流用兌現日算，不是開票日 |

三條規則：
- **按錯了往回轉要填原因**，並留下改不掉的紀錄——查帳時保護的是你
- D40 起你的編輯範圍只有金流——進度補登（推批次、按完成）找經理
- 客戶帳期在 設定 → 客戶 維護（你看得到、改要經理）。
  **帳期沒填，現金流的收款日就是猜的**

## 常見問題

**「金額要填未稅還是稅後」**——**一律填稅後的實際金額**（D48 老闆確認）。
系統不再自動加 5%：填多少，現金流就算多少、實際收付就是多少。

**「現金流是空的」**——應收要嘛已請款、要嘛有預計請款日、要嘛掛了有排程的觸發流程。
三個都沒有的錢，系統不編日期。

**「這一期金額怪怪的」**——金額＝有效合約額（沒簽約用估價金額）×比例，
追加減帳走「變更追加單」，核准後未請款的期數自動重算；**已請款的不會動**。

**「甘特圖上某個流程沒有橫條」**——列都在（左欄名稱不會消失），沒排日期的標
「未排日期」、排在畫面外的釘「◀ 起~訖」。到專案排程表補日期，或拖曳過去看。

**「流程想拿掉但已經做了一半」**——「編輯流程」取消勾選會標成**不適用**留下歷史，
不會刪掉；勾回來就還原。完全沒動過的才會直接移除。
自訂流程取消勾選＝刪除（做過的一樣會被擋下來）。

**「卡片開著的時候左邊的頁面呢」**——照常用（D49）。桌機上卡片是版面的
右欄，左邊的頁面被往左擠、兩邊都能點選捲動；點別的流程＝同一個側欄換內容，
永遠只有一層。關閉靠 X 或 Esc。

**「員工離職」**——設定 → 員工 → 停用。**不能刪**：他做過的操作紀錄都掛在他名下。

**「要改流程目錄的內容」**——分兩層（D40/D49）：
**單一案子**的工作內容、順序、加自訂流程直接在案子上改（經理）；
**新案的預設值**（模板有幾套、各套的項目與預設順序、工作內容三欄）
在 **設定 → 流程模板** 改（經理與系統管理員）。改模板不會回頭動已建的案子。
