# 員工手冊

> 2026-08-13 全面簡化。五個分頁、三種角色，畫面上的提示就是操作說明——
> 這份手冊只講畫面上看不到的事。

## 系統在做什麼（30 秒版）

追三件事：**案子做到哪、錢收付到哪、未來會不會缺錢。**

```
總覽      今天有什麼要處理（需要關注清單）
專案      一個案子＝合約＋請款分期＋底下的批次/工項
追蹤看板  東西現在卡在哪一站（欄位最高的就是瓶頸）
金流      應收（業主的錢）｜應付（付包商的錢）｜現金流預測
設定      客戶、廠商、員工（限經營者）
```

三種角色：**經營者**（都能做）、**會計**（輸入與金流，「核可付款」「刪專案」除外）、
**檢視**（看得到進度，看不到任何金額——含合約 PDF）。

---

## 老闆的一頁

每天打開看**總覽**就夠了：

1. **需要關注清單**——每一項都寫著「為什麼在這裡、該做什麼」。清單空的就沒事
2. 紅字優先：「可請款放著沒開單」是最容易漏掉的錢
3. 每週看一次 **金流 → 現金流預測**：累計轉負的那一格＝要調頭寸的時候

只有你能做的三件事：**核可付款**（金流→應付）、**核准變更追加單**（專案明細）、
**維護基礎資料**（設定分頁）。

## 會計的一頁

日常就三個動作，全在**金流**分頁：

| 事情發生 | 你做什麼 |
|---|---|
| 合約條件到了（如貨到驗收） | 應收 → 那一期按「變更狀態」→ 可請款 |
| 單開出去了 | → 已請款（填請款日，**預計收款日會自動算**：請款日＋客戶帳期） |
| 錢進來了 | → 已收款 |
| 包商送計價單來 | 應付 → 登錄計價（稅額自動加 5%，免稅請明確填 0） |
| 老闆核可後付款 | → 已付款。**開支票一定要填票期**——現金流用兌現日算，不是開票日 |

**錢怎麼算**：應收＝合約額×各期比例（變更單核准後未請款的自動重算）。
應付＝分包合約（承諾的成本）＋各期計價（實際發生，包商送單來登錄）。
專案損益的「已簽約」口徑用前者、「已計價」用後者。

三條規則：
- **按錯了往回轉要填原因**，並留下改不掉的紀錄——查帳時保護的是你
- 進度補登在 專案 → 展開案子 → 追蹤單元（推進站別、填完成數量）
- 客戶帳期在 設定 → 客戶 維護。**帳期沒填，現金流的收款日就是猜的**

## 建一個新案子（1 個表單）

專案分頁 →「新增專案」：

1. 案名、類型、客戶、負責人、合約金額
2. **請款分期照合約抄**——點 30/40/30 之類的模板帶入再改，或自訂。
   每期可填「預計請款日」（現金流預估靠它，之後隨時可改）
3. **合約 PDF 與設計圖直接在表單裡選好**，按「建立」一次完成

之後到案子明細裡「新增追蹤單元」建批次或工項。
**土建工項選了分包商可以順手填分包金額**——系統自動建立分包合約，
出現在金流→應付，這個案子的成本從此算得出來。分期漏填的話，明細裡隨時「加一期」。

## 常見問題

**「現金流是空的」**——應收款要嘛已請款（有預計收款日）、要嘛填了預計請款日。
兩個都沒有的錢，系統不編日期。

**「這一期金額怪怪的」**——金額＝有效合約額×比例，追加減帳走「變更追加單」，
核准後未請款的期數自動重算；**已請款的不會動**（送出去的數字不能改）。

**「檢視角色說看不到東西」**——正常。檢視看得到案子與進度，
看不到任何金額，合約與請款單類的檔案也不會出現。

**「員工離職」**——設定 → 員工 → 停用。**不能刪**：他做過的操作紀錄都掛在他名下。

**「要改流程站別」**——後台 `/admin/` → 階段模板。站是設定出來的，不用改程式。
